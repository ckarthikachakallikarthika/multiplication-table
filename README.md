# Multiplication Table 📊

## Description

Multiplication Table is a simple Python program that generates the multiplication table of a number entered by the user.

The program displays the table from **1 to 10**.

## Features

* Simple and beginner-friendly
* Accepts user input
* Generates a multiplication table
* Uses a `for` loop
* Displays results clearly

## Technologies Used

* Python 3

## How It Works

The program takes a number from the user and uses a `for` loop to multiply it by numbers from **1 to 10**.

For example, if the input is `5`:

```text
5 × 1 = 5
5 × 2 = 10
...
5 × 10 = 50
```
